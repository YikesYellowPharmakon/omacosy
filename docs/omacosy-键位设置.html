omacosy 当前键位设置

导出时间：2026-09-21 · 窗口管理器：AeroSpace · Super = Option（⌥）

Super 就是 Option（⌥）。Command（⌘）继续走 macOS 原键：复制粘贴、关标签、退出 App、⌘Tab 切 App。
Caps Lock 仍是 Caps Lock，方便中文输入法。Karabiner 没有改 Super。
系统菜单栏平时永久隐藏，不会和顶栏叠在一起；只有系统原生全屏时，鼠标移到顶端才会滑出系统栏和三个圆钮。

启动与窗口

键位作用
⌥ Enter打开终端 Ghostty
⌥ Shift Enter打开浏览器 Chrome
⌥ Space打开 Spotlight（搜 App、文件、菜单项、设置）。⌘Space 同样是 Spotlight
⌥ K打开 / 关闭键位提示（Esc 也可关）
⌥ W 或 ⌥ Q关闭当前窗口（⌘W 仍是关标签）
⌥ Shift F打开家目录（Finder）
⌥ Shift M打开网易云音乐
⌥ Shift G打开 ChatGPT
⌃ ⌥ L立刻锁屏

焦点与移动

键位作用
⌥ ← ⌥ ↓ ⌥ ↑ ⌥ →按方向聚焦窗口（文本里跳词请用 ⌃方向 或 ⌘方向）
⌥ Shift ←↓↑→把当前窗口按方向挪到隔壁格子
⌥ `在本工作区循环窗口（含浮动窗）
⌥ Shift `反向循环本工作区窗口
⌥ S把下一个浮动窗口捞到前面，并带上鼠标

⌘Tab 仍是系统 App 切换；⌘` 仍是同一 App 的窗口循环。

布局

键位作用
⌥ T当前窗口 平铺 / 浮动
⌥ J切换分割方向（横劈 / 竖劈）
⌥ - / ⌥ =缩小 / 放大当前窗
⌥ FAeroSpace 全屏：窗口盖住顶栏，仍留在当前工作区。再按一次退出。鼠标移到屏幕最顶端，顶栏会浮上来
⌥ N系统原生全屏（独立桌面，和绿钮一样）。圆钮在自动隐藏的菜单栏里，鼠标移到顶端即可
⌥ R进入调整大小模式
⌥ Shift ;进入服务模式

窗口自动平铺：两个左右分，更多递减分割。⌥T 只切换当前窗口平铺/浮动。绿钮（悬停/长按）是系统分屏，官方关不掉，也和 omacosy 的可用区域对不齐；不要用它排窗口。Esc 不能退出全屏。系统菜单栏平时永久隐藏；只有系统原生全屏时，鼠标移到顶端才会滑出系统栏和三个圆钮。

工作区与显示器

键位作用
⌥ 1 … ⌥ 9切到当前显示器的工作区 1–9
⌥ Shift 1 … ⌥ Shift 9把窗口移到工作区 N 并跟过去
⌥ Tab当前显示器的下一个工作区
⌥ Shift Tab当前显示器的上一个工作区
⌃ ⌥ Tab在最近两个工作区之间来回
⌃ ⌥ Shift Tab焦点切到下一台显示器
⌥ Shift O把当前窗口扔到另一台显示器的同一槽位
⌥ Shift Space把整个工作区扔到另一台显示器

主屏工作区 1–9，外接屏 11–19，末位数字是同一槽。拔掉外接屏时，外接屏上的窗口会折进主屏空槽。

主题

键位作用
⌥ Shift T切到下一套主题（也可点顶栏苹果菜单里的 Next Theme）
⌥ Shift B切到当前主题的下一张壁纸

现有主题：azure、enter-the-matrix、monokai-dark、snow-black。当前是 enter-the-matrix。每个主题记住上次选过的颜色和壁纸，切换回来还是那套。没有单独的主题列表或颜色选择快捷键。桌面数字雨默认关闭。

原来 menu bar 上的功能怎么用

系统 File / 编辑 / 显示 菜单栏不出现。也不再从 App 名称弹出菜单。下面这些键和入口仍然有效。

原来菜单里的事现在怎么做
新窗口 / 新标签⌘ N / ⌘ T
打开 / 保存 / 另存为⌘ O / ⌘ S / ⌘ Shift S
关闭标签 / 关闭窗口 / 退出 App⌘ W / ⌥ W / ⌘ Q
剪切 / 复制 / 粘贴 / 全选 / 撤销 / 重做⌘ X ⌘ C ⌘ V ⌘ A ⌘ Z ⌘ Shift Z
查找⌘ F
隐藏当前 App / 隐藏其它⌘ H / ⌘ ⌥ H
当前 App 的设置⌘ ,
关于本机 / 系统设置 / 锁屏 / 睡眠 / 重启 / 关机点顶栏左边苹果图标
屏保 / 下一主题苹果菜单里的 Screensaver、Next Theme；锁屏也可用 ⌃ ⌥ L
记不清某个菜单项⌥ Space 或 ⌘ Space 打开 Spotlight 搜索

各 App 自己的 ⌘ 快捷键都还在，只是不能再用鼠标去点那条系统菜单栏。

调整大小模式（先按 ⌥R）

键位作用
H / L宽度 −50 / +50
J / K高度 +50 / −50
- / =智能缩放
Enter 或 Esc回到普通模式

服务模式（先按 ⌥ Shift ;）

键位作用
Esc重载 AeroSpace 配置并回到普通模式
R拍平当前工作区布局树
Delete ⌫关掉本工作区除当前以外的窗口

触控板手势（四指）

手势作用
四指左右滑切换当前指针所在显示器的工作区（跟随系统自然滑动方向，含空工作区，循环到头）
四指上滑打开工作区总览
四指向下滑关闭工作区总览

系统自带的四指 Mission Control / 滑桌面已被关掉，避免和 omacosy 手势抢同一套动作。页面处于系统原生全屏时，左右滑或总览里点数字会先离开全屏再切工作区；划回原工作区会重新进入全屏。

工作区总览里

键位 / 操作作用
点击卡片 / 底部数字 或 1–9切到对应工作区（系统原生全屏里同样有效）
拖动卡片重排工作区
直接打字按窗口标题搜索
Enter进入第一个搜索结果
Esc有搜索先清空；再按关闭总览
四指向下滑关闭总览

顶栏（omacosy-bar）

操作作用
点左边苹果图标About This Mac、System Settings、Lock Screen、Screensaver、Sleep、Restart、Shut Down、Next Theme。有辅助功能权限时，还会带上系统苹果菜单里的其它项
点工作区数字切换工作区
Spotify 在播时中间的媒体胶囊上一首 / 播放暂停 / 下一首；点歌名打开 Spotify
天气 / Wi-Fi / 蓝牙点击弹出详情
亮度胶囊：滚轮 / 点击调亮度；滚过 0 会继续用遮罩把屏压得更暗；弹出里还有夜览开关
音量胶囊：滚轮 / 点击调音量；弹出里是滑杆和输出设备
电池打开系统电池设置
铃铛图标打开通知中心看消息
时钟弹出月历
最右边活动图标打开 Ghostty 里的 btop
平时 / 全屏平时只有 omacosy 顶栏。系统菜单栏埋掉。⌥F 全屏时顶栏被盖住，鼠标移到顶端会再浮上来

屏保

入口作用
闲置自动所有主题都是 Ghostty + ttfx 屏保
苹果菜单 → Screensaver立刻开屏保

按键或点击会退出屏保并锁屏。系统设置里的 ScreenSaverEngine 不是这条路径。鼠标停在 Dock 上时开屏保，光标会移开，Dock 会收起。
